# Naming conventions

- Mod element names: CamelCase, English, descriptive and unique (`RubyIngot`, `RubyOre`, `DeepslateRubyOre`,
  `RubySword`, `RubyArmor`, `RubyGolem`). Registry names are derived as snake_case (`ruby_ingot`).
- Display names: Title Case as vanilla ("Ruby Ingot", "Block of Ruby", "Deepslate Ruby Ore").
- Textures and sounds: lower_snake_case (`ruby_ingot`, `ruby_ore`, `entity.ruby_golem.hurt`).
- Procedures: verb-first describing behavior (`RubySwordHitEntity`, `SpawnRubyParticles`).
- Use folders to group elements by feature (Ruby/Tools, Ruby/Blocks, Mobs/RubyGolem).
- Mod ID: lowercase, no spaces, unique on CurseForge/Modrinth. Do not reuse vanilla names for elements.
