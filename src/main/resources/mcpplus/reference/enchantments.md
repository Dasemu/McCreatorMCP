# Vanilla enchantment levels (Java Edition)

| Enchantment       | Max level | Applies to            |
|-------------------|----------:|-----------------------|
| Protection        | 4 | armor                     |
| Fire/Blast/Projectile protection | 4 | armor      |
| Feather falling   | 4 | boots                     |
| Thorns            | 3 | armor                     |
| Unbreaking        | 3 | any damageable item       |
| Mending           | 1 | any damageable item (treasure) |
| Sharpness         | 5 | sword, axe                |
| Smite / Bane of arthropods | 5 | sword, axe       |
| Fire aspect       | 2 | sword                     |
| Looting           | 3 | sword                     |
| Sweeping edge     | 3 | sword                     |
| Efficiency        | 5 | tools                     |
| Fortune           | 3 | tools                     |
| Silk touch        | 1 | tools                     |
| Power             | 5 | bow                       |
| Infinity          | 1 | bow                       |

Advice for `enchantment` elements: keep max level 1-5, mark strong ones as treasure, define incompatible
enchantments and supported items (tags), and keep the cost curve similar to vanilla.
